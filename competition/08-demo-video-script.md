# 效果演示视频分镜脚本

> 本脚本用于录制赛题要求的“效果演示视频”，覆盖偏好捕捉、知识整合、检索复用三项核心功能。
> 所有演示命令均为仓库真实可执行命令；录制环境为银河麒麟 V11 虚拟机或等价桌面环境。
> 预计成片时长 6–8 分钟；正式视频文件不纳入仓库，录制后随竞赛材料提交。

## 录制前置条件

1. 后端服务已启动：`uvicorn backend.app.main:app --port 8010`，环境变量 `WANWEI_API_KEY` 已配置；
2. 演示用 API key 就绪（替换下文 `<key>`）；
3. 屏幕录制工具已开启（麒麟自带录屏或 OBS），分辨率 ≥1920×1080；
4. 终端字体调大至评委可读（建议 ≥16pt）。

## 分镜

### 场景 1：开场与定位（0:00–0:40）

- 画面：README 首页与整体架构图（`assets/mindmap/wanwei_shuyi_osagent_2_0_mindmap.png`）。
- 口播要点：核心问题——AI 记忆“记得住”但“管不住”；本方案提供可验证的记忆治理层。
- 口播须说明图中英文术语：EGPM（偏好记忆治理闭环）、TKE（知识双时态演化）、RRF（倒数排名融合）。

### 场景 2：偏好捕捉（0:40–2:00）

- 操作：在控制台连续完成两轮交互，第一轮明确表达“此类文件走加急流程”，第二轮展示系统引用该偏好。
- 终端同步执行 `python scripts/bench_egpm.py` 展示偏好评测基准的真实输出。
- 口播要点：Beta 后验（贝塔分布后验更新）如何随证据调整置信度；情感信号如何作为证据接入。
- 证据指向：`reports/` 下评测输出；指标口径 91.7%（MEB full hybrid 组）。

### 场景 3：知识整合与冲突消解（2:00–3:30)

- 操作：先后写入同一事实的两个版本（如“报销标准 v1 / v2”），展示冲突检测提示与演化链；执行 as-of 历史回放（按有效时间 / 按系统当时所知两种模式）。
- 终端执行 `PYTHONPATH=. python scripts/bench_tke.py`，展示 TKE 基准四场景双 100% 输出。
- 口播要点：冲突不是覆盖旧知识，而是建立可追溯的版本演化链。

### 场景 4：检索复用与响应时间（3:30–5:00）

- 操作：跨会话提问，展示三路召回（全文 / 向量 / 图）经 RRF 融合后的排序结果与引用来源。
- 画面：麒麟实机延迟实测数据（`reports/kylin-native-sdk-evidence/latency.json`）与规模曲线（`reports/latency_scale.json`）。
- 口播要点：p95 83ms，对比赛题 ≤500ms 指标的 6 倍余量；10k 条记忆 p95 97.4ms。

### 场景 5：可证明删除（5:00–6:30）

- 操作：执行 `python scripts/demo_governance.py --api-key <key>` 完整流程——敏感记忆标记、跨会话召回、硬删除、五处残留逐项验证为零、导出含审计编号的 PDF 删除证书。
- 口播要点：这是治理层区别于聊天客户端的核心能力；证书可归档备查。

### 场景 6：麒麟适配与收尾（6:30–7:30）

- 画面：麒麟 V11 桌面环境下的 Electron 桌面端、deb 安装过程、托盘与 UKUI 主题适配。
- 口播要点：端侧单进程 + 单 SQLite 文件的轻量化部署；145 项手机 API 麒麟实机验收通过。

## 录制注意事项

- 演示脚本不会伪造成功结果：若某一步失败，停止录制并排查，不得剪辑掩盖；
- 视频中出现的所有数字必须与 `reports/` 原始证据一致；
- 口播避免 AI 化表述，技术名词按本脚本括号内中文标注讲解。
