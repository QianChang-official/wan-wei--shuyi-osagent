## 十、IQ × MQ 二维模型

### 10.1 为什么必须分开测

当前所有主流基准都在测**一种**能力：
- LongMemEval / LoCoMo / BEAM → 测"能不能记住"（记忆能力）
- ARC-AGI / MMLU / GPQA → 测"能不能推理"（智能能力）

但它们是**两个正交维度**。把两者混在一个分数里，会导致：
- 一个"大号知识库"（MQ 高、IQ 低）被误判为强 Agent
- 一个"强推理但记不住用户"的模型被误判为弱助手

**一句话框架**：记忆是智能的材料库与工作空间；智能是对记忆进行选择、压缩、更新、组合和行动化的控制能力。

### 10.2 二维矩阵

| | **MQ 低** | **MQ 高** |
|---|---|---|
| **IQ 低** | 普通助手（单次对话可用，无状态） | 大号知识库（记得多，但不会用） |
| **IQ 高** | GPT 类强模型（单次推理强，跨会话失忆） | **真正的 Agent**（记得住 + 会用） |

四个象限代表四种真实产品形态：
- **普通助手**：无长期记忆、推理一般——早期聊天机器人
- **大号知识库**：海量记忆、检索强、但不会推理组合——纯 RAG 系统
- **GPT 类模型**：推理强、但跨会话不记得用户——强模型单次问答
- **真正 Agent**：两者兼备——记忆系统 + 推理控制力的结合

### 10.3 MQ 的定义

**Memory Quotient（MQ）** = 系统在跨会话/跨任务情境下，对记忆进行**写入 → 检索 → 更新 → 遗忘 → 安全治理**全生命周期操作的效能度量。

MQ 由五种子能力构成：
1. **写入精度**：能否从交互中正确抽取值得记的事实（不误记、不过度记忆）
2. **检索效率**：能否在正确时机召回正确记忆（precision@k、噪声抑制）
3. **更新正确性**：新旧事实冲突时能否正确覆盖（版本链、时效失效）
4. **遗忘可控性**：能否精准删除/降权（Deletion Completeness、纠错恢复）
5. **安全治理**：能否防止记忆投毒、泄漏、权限越界（Harm 维度）

### 10.4 IQ × MQ 与未来基准的分化

未来评测体系会分裂成两条独立赛道：
- **ARC-AGI 系** → 测 IQ（纯推理，无记忆干扰，单次任务）
- **LongMemEval 系 → MHEB 系** → 测 MQ（记忆全生命周期 + Harm + Economics）

**预测**：随着 Agent 框架成熟，MQ 会从"辅助指标"升级为"核心卖点"——因为**推理能力越来越商品化（模型竞赛），而记忆治理能力是产品差异化的护城河**。

### 10.5 对宛委·枢忆的定位含义

按此框架，项目当前处于：
- **MQ：中等**（写入/检索基础可用，但更新/遗忘/安全治理有缺口——对应 2.docx 的五大缺口）
- **IQ：取决于所接模型**（推理能力由外部 LLM 提供）

**战略含义**：宛委·枢忆不应该跟模型拼 IQ（拼不过、也没必要），**应该把"IQ × MQ 矩阵中的 MQ 高 + IQ 借用"象限作为产品定位**——端侧记忆治理 + 接入任意强模型 = "大号知识库"升级为"真正的 Agent 底座"。

### 10.6 评测建议

- IQ 评测：沿用 ARC-AGI / MMLU / GPQA（不重复造轮子）
- MQ 评测：用本体系第 3 章 Memory Experience Benchmark + 第 6 章 MHEB
- 产品定位图：每个产品在 IQ × MQ 平面上的坐标 + 迁移路径

## 附录：从认知科学看 IQ/MQ（5.docx 要点提炼）

1. 工作记忆与流体智力：相关 ~0.48-0.72，但因果只解释 ~15% 方差
2. 记忆训练远迁移效果很小——"训练记忆 ≠ 提升智力"
3. 长期记忆对问题解决的贡献在于"受控检索"和"按任务选择"，不只在于"存着"
4. 结论：**"高记忆低智力"完全存在（大知识库弱推理）；"高智力低记忆"也存在（强模型跨会话失忆）**
